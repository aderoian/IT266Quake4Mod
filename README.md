# Quake Tower Defense

A Quake 4 mod created by Armen Deroia for NJIT IT266.

## Installation
1. Install Quake 4 from steam
2. Naviage to the Quake 4 install folder. (usually C:\Program Files (x86)\Steam\steamapps\common\Quake 4\)
3. Download the 3 files from releases (pak001.pk4, game000.pk4, Quake4Config.cfg)
4. Create a new folder called "tower_defense" in the "Quake 4" folder.
5. Move the download files into this folder.
6. Launch Quake 4 through Steam and select "tower_defense" from the mods menu.

## Playing
You will spawn in a flat area where you must build your base of towers. There is a in-game help menu, press 'h' to view. This will show you a list of the defensive and economy towers.

Monsters will spawn in waves, you must keep building new towers and upgrading existing towers to survive. Towers cost resources to build, your economy towers will generate resources for later use.
